# Intuit Plugins

Official Intuit marketplace for AI coding agent plugins (Claude Code and Codex). Each plugin lives in its own folder under `plugins/`.

## Plugins

| Plugin | Description |
| --- | --- |
| [intuit-developer](plugins/intuit-developer) | Build QuickBooks integrations with Intuit Developer Platform: workspace and app setup, sandbox management, browser OAuth, and verified QuickBooks API calls. |
